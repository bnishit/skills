# Word Swaps

Always prefer the simpler word. The test: would a smart 14-year-old understand this without looking it up?

| facilitate | help, enable |
| leverage | use |
| optimize | improve |
| comprehensive | full, complete |
| subsequently | then, after |
| approximately | about, roughly |
| demonstrate | show |
| functionality | feature, what it does |
| methodology | method, approach |
| proliferation | spread, growth |
| aforementioned | this, that, the above |
| notwithstanding | despite, even though |
| constitutes | is, makes up |
| endeavor | try, effort |
| commence | start, begin |
| terminate | end, stop |
| ascertain | find out |
| disseminate | share, send |
| prerequisite | requirement, needed first |

## Business Jargon → Plain Language

| Do not use | Use instead |
|------------|-------------|
| navigate (challenges) | handle, deal with |
| unpack (analysis) | explain, look at |
| lean into | accept, go with |
| landscape | situation, market |
| game-changer | big deal, important |
| double down | commit, push harder |
| deep dive | close look, detailed review |
| circle back | come back to, revisit |
| move the needle | make a difference, improve |
| low-hanging fruit | easy wins, quick fixes |
| boil the ocean | try to do too much |
| take offline | discuss separately |

## Sentence Structure

Keep it flat. Avoid:
- Nested clauses ("The team, which had been working on the feature since Q2, decided, after reviewing the data, to pivot.")
- Passive voice when active works ("The bug was found by QA" → "QA found the bug")
- Nominalization — turning verbs into nouns ("The implementation of the feature" → "We built the feature")
